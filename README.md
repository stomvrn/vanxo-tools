# VanXo · Инструменты

14 офлайн-утилит в одном HTML-файле. Работают без интернета, без сервера, без регистрации. Данные не покидают браузер.

**URN:** `urn:vanxo:artifact:tools:1.0.0`  
**Автор:** Холин Иван Алексеевич (VanXo)  
**Дата:** 2026-10-03  
**Статус:** CANONICAL

## Утилиты

| # | Название | Что делает |
|---|---|---|
| 1 | Счётчик | Символы, слова, знаки, время чтения |
| 2 | Регистр | 5 режимов смены регистра |
| 3 | Частоты | Частотный анализ слов |
| 4 | Lorem | Генератор заглушек |
| 5 | JSON | Форматтер, минификатор, валидатор |
| 6 | Base64 | Кодирование/декодирование UTF-8 |
| 7 | Хеш | SHA-256/384/512 |
| 8 | URL | encodeURIComponent / decodeURIComponent |
| 9 | Время | Unix timestamp ↔ дата |
| 10 | UTM | Генератор ссылок с метками |
| 11 | Транслит | Кириллица → латиница |
| 12 | Пароли | Криптостойкий генератор |
| 13 | Цвет | HEX ↔ RGB ↔ HSL + контраст |
| 14 | Diff | Построчное сравнение текстов |

## Использование

Открой `index.html` в браузере. Всё.  
Или: https://stomvrn.github.io/vanxo-tools/

Горячие клавиши: `Ctrl+K` — палитра команд, `1–9` — быстрый переход.

## Инварианты

- **Offline-first** — работает без сети
- **Zero-dependencies** — без CDN, npm, внешних библиотек
- **Single-file** — один HTML
- **CSP-first** — строгая Content-Security-Policy
- **Local data** — localStorage, не облако
- **No telemetry** — никаких запросов
